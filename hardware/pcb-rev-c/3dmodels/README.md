# 3D models for documentation renders

These models are used only by `tools/make_doc_renders.py` to draw the carrier
with its modules fitted (`docs/images/pcb/`). The PCB project and fabrication
files do not reference them.

---

## Models

| Module         | File                            | Source                                         |
|:---------------|:--------------------------------|:-----------------------------------------------|
| M2 Pro Mini    | `snapeda/Arduino_Pro_Mini.step` | SnapEDA (SnapMagic), not in git – see below    |
| M2 Pro Mini    | `Pro_Mini_standin.wrl`          | Stand-in, used when the SnapEDA file is absent |
| M3 D1 Mini     | `D1_Mini_standin.wrl`           | Stand-in                                       |
| M1 TP4056      | `TP4056_USBC_standin.wrl`       | Stand-in                                       |

The stand-ins are generated by `tools/make_module_models.py` from the measured
outlines, pin rows and main parts in `tools/design.py`. They are block models
for fit and stacking, not manufacturer models, and are CC0 like the rest of
the project.

---

## SnapEDA Arduino Pro Mini

- **Source:** [SnapEDA – Arduino Pro Mini](https://www.snapeda.com/parts/Arduino%20Pro%20Mini/Arduino/view-part/),
  3D model download (`Arduino Pro Mini--3DModel-STEP-510211.STEP`).
- **Licence:** SnapEDA models are CC BY-SA 4.0 with the SnapEDA Design
  Exception 1.0. Rendered images that show the model credit SnapEDA. The
  raw file is not redistributed here, so `snapeda/` is gitignored.
- **What the file says:** AP214 STEP exported by SolidWorks 2021 (SwSTEP 2.0)
  on 13-Nov-2023, in millimetres. Its part names (`ATMEGA328_ATMEGA168`,
  `RESONATOR1_1`, `V_REG_LDOSMD`, `CAP0603-CAP`, `CAP_POL1206`,
  `RESISTOR0603-RES`, `SMD-ALT01`) are SparkFun Eagle library names, so the
  model follows the SparkFun Pro Mini layout.
- **Size and pins:** board 17.78 × 33.02 mm. Rows 15.24 mm apart, pin 1 about
  3.8 mm from the serial end, matching the carrier sockets. It has no header
  pins; the renders add them.
- **Differences from the reference board:** the BTE13-010A clone has the same
  pin positions but a different part placement, so the top side in the
  renders is illustrative.
- **Placement in renders:** on `JM2L1`, offset (7.62, –12.77, 11.04) mm,
  rotated –90° about X (the export is Y-up, origin at the board centre).

To use it, download the STEP from the page above and save it as
`snapeda/Arduino_Pro_Mini.step`, then run `tools/make_doc_renders.py`.

## Wanted: D1 Mini and TP4056 models

The stand-ins can be swapped for real models when ones with a clear licence
turn up. Add the file here, then set its path, offset and rotation in
`tools/make_doc_renders.py`, using the Pro Mini entry as the pattern. Check
the pin rows land on the socket holes in a top-view render before using it.
